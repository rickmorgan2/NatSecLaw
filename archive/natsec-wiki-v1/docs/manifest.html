Manifest

Every document in the wiki and every source it links to.

The manifest is rebuilt from data/ on every render, so it always matches the pages. The same tables are saved as plain files: manifest_documents.csv and manifest_sources.csv.

Documents

One row per statute, 82 in all.

Source links

One row per link, 148 in all. Primary links are built from each statute’s citation; secondary links are the reports and articles used for current-status notes.

Reference sources

General sources used across the wiki and worth checking first when verifying or extending a page.

Project files

File Contents
