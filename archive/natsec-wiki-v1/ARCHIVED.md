# Archived: version 1

This is the first version of the national security legislation wiki, as it stood on November 10, 2026, before version 2. It is kept unchanged for reference; edit `../../natsec-wiki/` instead.

Version 1 had one member lens, identified by district only (CO-06), linked statutes to the Cornell LII copy of the U.S. Code, and had no study guide. Its built site in `docs/` is copied into the version 2 site under `v1/` on every full render.

The README and CLAUDE_README in this folder describe version 1 and its old location (`CO-06/natsec-wiki`).
