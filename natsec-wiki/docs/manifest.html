Manifest

Every document in the wiki and every file in the project.

The manifest is rebuilt from data/ on every render, so it always matches the pages. The tables are also saved as plain files: manifest_documents.csv, manifest_sources.csv, and all_sources.csv. Source links are listed on the Sources page.

Project files

File Contents
data/statutes/*.yml The wiki content, one entry per statute, in files grouped by domain. 08_civilian_harm.yml holds the civilian harm statutes.
data/edges.csv The knowledge graph: one row per relationship between two statutes.
data/members/*.yml One file per member lens: committees, record, and district interests, each with its own source.
data/study/units.yml The study guide’s units: objectives, reading paths, key terms, and review questions.
data/reference_sources.csv General reference sources.
data/research_sources.csv Sources consulted for this edition.
data/manifest_documents.csv, data/manifest_sources.csv, data/all_sources.csv Generated. The documents table above and the source lists.
R/helpers.R Data loading, vocabularies, layers, eras, and official link builders.
R/build_pages.R Validates the data and writes the statute, member, and unit pages, the site data, and the manifests.
R/post_render.R Copies the archived version 1 into docs/v1.
R/deploy.R Local runner: preview, render, serve, or zip the site.
assets/graph.js The knowledge graph’s controls.
_includes/site.html Site-wide script: the current-law switch, historic link marks, and study progress.
statutes/*.qmd, members/*.qmd (except index.qmd and _lens.qmd), study/units/*.qmd Generated pages.
CLAUDE_README.md Context file for working on this project in another Claude session.

Independent reference project. Not affiliated with any congressional office. Not legal advice; check citations against the linked official text.
